# DanaQR

A Palm OS 4.1 application for the **AlphaSmart Dana** that converts text into
QR codes, so you can move text off the device and onto a phone without a
cable, IrDA, or SD card shuffle.

Workflow:

1. Select text in AlphaWord, copy it.
2. Launch **DanaQR**.
3. Press **Paste** (or Ctrl+V into the field) to load the clipboard.
4. Press **Gen** to encode. Long text is split into multiple QR frames.
5. **Cycle** through the frames automatically, or **Next** to step manually.
6. Scan each frame with any QR reader on your phone.

Text longer than a single QR code can hold is split into numbered chunks
(`Q01/05: ...`) and cycled on screen. A scanning app that supports multi-frame
reading (e.g. *QRScan*) can collect all of them; a plain single-frame reader
will capture whichever frame is visible when you hit the shutter.

## AI disclosure

The initial codebase was generated by an AI assistant at the request of the
maintainer. The maintainer then debugged the build, fixed several functional
bugs, and tested the result on real hardware (AlphaSmart Dana, Palm OS 4.1).
The code works but has not been reviewed for style or idiomatic Palm OS
conventions. Contributions and corrections are welcome.

## Requirements

- An AlphaSmart Dana running Palm OS 4.1 (or a Palm OS 4.x emulator such as
  POSE).
- A Linux or WSL2 host for building. The instructions below assume Ubuntu
  20.04 ("focal") on WSL2, which is what the project was developed against.
- The `prc-tools` cross-compiler for m68k, the Palm OS SDK headers, and
  `pilrc` + `build-prc` for resource compilation and packaging.

## Building

### 1. Install the toolchain

The most reliable path is `prc-tools-remix`, which ships prebuilt Debian
packages for recent Ubuntu releases:

```bash
wget https://github.com/jichu4n/prc-tools-remix/releases/download/v2.3.5/prc-tools-remix_2.3.5.focal_amd64.deb
wget https://github.com/jichu4n/pilrc/releases/download/v2.3.90/pilrc_3.2.90.focal_amd64.deb

sudo dpkg -i prc-tools-remix_2.3.5.focal_amd64.deb
sudo dpkg -i pilrc_3.2.90.focal_amd64.deb
